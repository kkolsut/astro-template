# Lab notebook

Append-only. Newest entry at the bottom. This is the project's memory between
sessions — agents start cold every time, and a conversation that gets long is
summarised, so anything not written here is gone.

Record **decisions and dead ends**, not a diary of commands. The git log
already says what changed; this says why, and what was tried and abandoned so
nobody tries it twice.

Write an entry when:

- a question is set, narrowed, or dropped
- a dataset is chosen or rejected, with the reason
- a method is chosen over an alternative
- something does not work and you stop pursuing it — *especially* this
- a number that later text will depend on is produced
- a referee or review point is accepted or disputed

Format — absolute dates, never "yesterday" or "last week":

```
## YYYY-MM-DD — short title

**What:** the decision or finding, in a sentence or two.
**Why:** what made it the right call, with the number if there is one.
**Where:** files, scripts, or data products involved.
**Open:** what is still unresolved, if anything.
```
